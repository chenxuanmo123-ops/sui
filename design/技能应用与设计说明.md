# 数鉴 Agent · 技能应用与设计说明

日期：2026-10-13。范围：前端交互 demo，不代表 AI 系统已经完成。

## 实际采用的技能

| 技能 | 如何落实到页面 |
| --- | --- |
| frontend-design | 以分析工作台而非宣传首页为核心；把字段口径、图表与证据并列；减少装饰性渐变、虚构数据卡片与模拟日志。 |
| ui-ux-pro-max | 执行本地设计检索并检查设计规则；原生表单与显式标签关联、键盘焦点、可见错误反馈、手机触控目标、响应式布局、减少动画偏好。当前主题为浅色画布 + 深色导航，没有交付主题切换。 |
| webapp-testing | 使用 Python Playwright、本机 Edge 检查真实数据加载、文件上传、口径变更、分支、来源定位、报告打开和不同屏宽。 |
| Pencil pen-dev | 制作可编辑的工作台概念稿，保留层级、容器与文字，导出 .pen 和 PNG；将设计转成 React 工作台。 |

未把技能名称当成实现效果的证明；采用的规则和测试均以当前代码为准。Pencil 概念稿是布局设计，不是可执行产品截图。实际 React 版增加了完整字段映射、数据表和来源检查，不声称逐像素一致。

## 视觉与信息架构

- 深蓝导航：品牌与三个真实页面入口（工作台、分支、来源）。
- 浅色画布：使表格、空值状态和计算结果保持清晰。
- 蓝色动作：执行分析；导入、来源和导出使用次级操作。
- 字号层次：页面标题、模块标题、正文、表格和辅助标签逐级区分，不做营销式超大标题。
- 使用系统中文字体，不依赖外部字体下载。
- 图标统一使用 Lucide；图表为可交互 SVG，同时提供结果表格。
- 空状态使用占位符与执行提示，不预造结果；进度只对应真实已经完成的动作。
- 移动端保持单列工作流，表格和图表只在自身容器内部横向滚动；主页面不产生横向溢出。

## 保留的边界

CSV 扫描是规则候选，通用业务语义需人工确认。公开数据自然语言入口是有限规则解析；LLM、AI 自主规划、SQL、XLSX、PDF 和多模态仍是后续实现。MCP 暂不接入。没有为了比赛视觉效果添加虚假业务数据或虚构模型执行。

## 2026-10-15 调整：业务目标驱动的 AI 辅助分析

复用现有 frontend-design、ui-ux-pro-max 与 webapp-testing 工作流。新的主入口先填写业务目标、数据粒度和口径，展示 AI 澄清与计划，再确认计算；原公开能源规则工具折叠为手动辅助。支持服务端兼容模型配置与多模型选择，未配置时不生成模拟回答。浏览器契约测试使用明确的接口替身，计算数据使用实际 OWID 子集；不能将其当作真实模型效果验证。Pencil 概念稿未同步新增 AI 表单，以运行代码为准。


## 2026-10-15：模型连接与分析画布改版

应用 frontend-design、ui-ux-pro-max 与 webapp-testing。本轮以数据分析工作台为对象，采用浅灰绿导航、白色画布与深绿动作，保留本地中文系统字体，避免外部字体加载依赖。ui-ux 搜索结果中的视频落地页不适合任务，未套用其页面结构；采纳键盘焦点、明确表单标签、渐进展示、响应式和减少动态效果等检查项。

由旧纵向表单和结果侧栏改为中央画布与右侧持续助手；模型连接独立弹窗，手动工具折叠。375/768/1024/1440 宽度检查主页面及弹窗溢出。Pencil 工具本轮未连接运行中的桌面应用，实际实现与验证以 React 页面为准，未将原 .pen 概念稿冒称为新版。
