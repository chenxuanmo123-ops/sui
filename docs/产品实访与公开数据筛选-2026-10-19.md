# 数鉴 Agent：产品实访、源码研究与公开数据筛选

核查日期：2026-10-19。目标是改善分析与可视化的实际价值，MCP 继续搁置，公网部署留到最后。本轮仅完成调研、源码查阅和原始数据核验，**没有把下面的建议记为已实现**。

## 1. 核查方法与证据

- 直接读取产品官网、官方文档与 GitHub 官方 API；固定具体提交，保存 README、目录树和相关源文件。
- 使用 Playwright / Edge 实际打开网页，并查看截图。Data Formulator 进入 Movies 现成示例会话，观察已有的分析过程与图表；未向第三方提交我们项目的数据，也没有发起新的模型分析来验证其模型能力。
- Evidence 观察的是官网产品演示画面，不是本轮真实业务数据分析；演示数字真实性未经独立核验。
- Graphic Walker 在线首页本轮返回 HTTP 200，但浏览器正文为空。其功能判断来自官方 README 和源码，不能写为已经完整体验其在线产品。
- 研究原文、截图、脚本、数据包和校验结果位于项目的 artifacts/product-research-2026-10-19 目录。

## 2. 值得学习的产品

### 2.1 Microsoft Data Formulator：保留分析过程与不同路径

入口：[官方在线演示](https://data-formulator.ai/)；[官方源码](https://github.com/microsoft/data-formulator)。

固定提交：5477f0e236426dc8f74a498ec400414fba7fbc0f；MIT。这里与此前研究同一提交，本轮新增研究的是分析线程和图表组织，而不是再次研究模型连接配置。

实际看到 Movies 示例中，问题从预算与票房的总体关系继续发展为预算区间比较、类型交叉热力图、分布与评分比较，再到综合报告。左侧保留提问与图表节点，右侧显示选中图表和表格。这里只观察交互，不独立认可示例中的数值结论、数据来源或计算正确性。

源码抽样：

- [DataThread.tsx](https://github.com/microsoft/data-formulator/blob/5477f0e236426dc8f74a498ec400414fba7fbc0f/src/views/DataThread.tsx#L560)：通过派生表和 parentNodeId 关联分析节点；后续代码按节点关系组织文本、图表和报告。
- [DataThreadCards.tsx](https://github.com/microsoft/data-formulator/blob/5477f0e236426dc8f74a498ec400414fba7fbc0f/src/views/DataThreadCards.tsx#L105)：图表卡片、选中与关联操作。

适合数鉴：每条追问保存它的来源分析、筛选范围和结果版本；从已有图表继续比较，允许回到前一个结果。我们的初版可以用清晰的历史卡片与分支入口，不必照搬密集的多列线程布局。

### 2.2 Graphic Walker：图表选择要进入实际查询

入口：[项目源码及说明](https://github.com/Kanaries/graphic-walker)；[在线入口](https://graphic-walker.kanaries.net/)。

固定提交：87e8e51d2d8e2e32d6c763d32a3357fe29f379a0；Apache-2.0。

官方将字段区分为维度与度量，提供图形编码、聚合、筛选及数据探索。源码明确展示了选择的图形如何变成明细查询的筛选条件：

- [dataBoard.tsx](https://github.com/Kanaries/graphic-walker/blob/87e8e51d2d8e2e32d6c763d32a3357fe29f379a0/packages/graphic-walker/src/components/dataBoard.tsx#L15)：选中图形的字段值转为过滤器，并与视图原有筛选合并，再交给数据表查询。
- [renderer/hooks.ts](https://github.com/Kanaries/graphic-walker/blob/87e8e51d2d8e2e32d6c763d32a3357fe29f379a0/packages/graphic-walker/src/renderer/hooks.ts#L31)：字段、维度、度量、过滤器和聚合组成查询工作流。
- [dateTimeDrill.ts](https://github.com/Kanaries/graphic-walker/blob/87e8e51d2d8e2e32d6c763d32a3357fe29f379a0/packages/graphic-walker/src/lib/op/dateTimeDrill.ts)：日期粒度转换实现。

适合数鉴：保留现有的点击图表查来源功能，在此基础上增加“仅分析这部分”“与其他分组比较”“在这个范围继续问 AI”；当前范围用可撤销的筛选标签显示。不能说我们完全没有图表下钻：现有 DataChart、ExplorationChart 已有点击来源能力，缺的是与后续分析及其他视图连起来。

### 2.3 Evidence：让图表成为可阅读的分析成果

入口：[官网演示](https://evidence.dev/)；[源码](https://github.com/evidence-dev/evidence)；[指标组件文档](https://docs.evidence.studio/components/big_value)。

固定提交：e02a06719afb648c023e2678a226c0e394b075d0；MIT。

官网演示把问答、图表、表格和发现放在一起；源码中，指标组件将当前值、比较配置、时间范围与趋势所需的查询参数明确组织起来。官网画面属于产品演示，其业务数字不能直接作为我们的真实案例。

- [schema.ts](https://github.com/evidence-dev/evidence/blob/e02a06719afb648c023e2678a226c0e394b075d0/core/src/user-components/tags/bigvalue/schema.ts#L154)：指标引用、聚合表达式、比较与筛选的约束。
- [build-bigvalue-sql.ts](https://github.com/evidence-dev/evidence/blob/e02a06719afb648c023e2678a226c0e394b075d0/core/src/user-components/tags/bigvalue/build-bigvalue-sql.ts#L37)：比较配置与查询参数的连接。

适合数鉴：一个问题形成完整分析页，先说明范围与口径，再展示关键数值、比较和相关图表，接着给出有证据的观察、限制与后续问题；报告导出覆盖整个分析，而不是只导出当前单个任务。

### 2.4 Metabase：明确点击图表后可以做什么

入口：[官方交互文档](https://www.metabase.com/docs/latest/dashboards/interactive)；[下钻文档](https://www.metabase.com/docs/latest/questions/visualizations/drill-through)。

已读取交互文档并通过浏览器核查页面。文档区分打开下钻菜单、导航到其他页面、更新仪表板筛选等点击行为，并说明可以将当前值传递给目标视图；同时说明部分能力对查询构建器问题与原生 SQL 问题不同。

适合数鉴：点击数据点后呈现清楚的动作菜单，切换图表、查看证据、继续分析分别表达。跨图联动需要维护一致的查询范围，不能只改变视觉高亮。本轮未安装或完整测试 Metabase，也未读取其源码，不把文档能力当作本项目现成组件。

### 2.5 Wren AI：先定义数据的业务含义

入口：[官方源码](https://github.com/Canner/WrenAI)。

固定提交：055830d786dbf9d2905e0f1095f18e889222a530。许可证按目录区分，不能把整个仓库统称 MIT 或 Apache；已读取根 LICENSE，core、sdk、skills、examples 等按其路径规则使用 Apache-2.0，其他部分需逐项核查。本轮只研究设计，无代码移植。

- [MDL 说明](https://github.com/Canner/WrenAI/blob/055830d786dbf9d2905e0f1095f18e889222a530/docs/core/concepts/what_is_mdl.md)：模型、字段、关系和计算定义描述数据含义，避免每次从结构重新猜测。
- [上下文说明](https://github.com/Canner/WrenAI/blob/055830d786dbf9d2905e0f1095f18e889222a530/docs/core/concepts/what_is_context.md)：将业务规则、定义和相关上下文提供给分析过程。

适合数鉴：把现在已有的场景定位、字段角色和可选背景沉淀为可修改、可复用的分析口径，包括每行代表什么、指标公式、单位、时间范围、枚举编码、排除规则。模型建议与用户确认要区分。不能仅凭数值类型决定对编号、百分比或价格求和，也不必强制用户填完所有背景才能先做安全的描述性检查。

## 3. 两份已实际下载并核验的真实公开数据

### 3.1 电商访问与购买转化

[UCI 原始发布页](https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset)。原始包 uci-online-shoppers.zip：1,072,219 字节；SHA-256：2972e6184d3ad7beaaa831d9fc2b059dc3ee29df69d1ec593c466a5cd8485d14。

逐行读取原始 online_shoppers_intention.csv：12,330 条、18 列，含流量类型、访客类型、月份、是否周末、产品页浏览及 Revenue 标记。TRUE/FALSE 标记中 TRUE 有 1,908 条，与发布页说明一致。

适合的问题：不同访客类型与流量类别的购买转化率、浏览行为与购买的关系、按月份和周末比较。

限制：Revenue 是是否产生购买的布尔标记，不是收入金额；TrafficType 是编码，不知道含义时只能按编码比较，不能擅自命名为广告、自然搜索等渠道。月份缺少完整年份与日级日期，不能制造完整日趋势；行为指标与购买仅能做描述性关系分析。该数据为历史研究数据，不表示当前中国电商市场，更不代表外卖平台份额。转化率需要分子/分母计算，我们现有六类单指标聚合不能直接宣称已经完整支持。

### 3.2 共享单车使用需求

[UCI 原始发布页](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset)。原始 Readme 说明数据来自华盛顿 Capital Bikeshare 的 2011—2012 年历史记录，并聚合为小时、日级记录，结合天气等信息。

原始包 uci-bike-sharing.zip：279,992 字节；SHA-256：b70182d0d0508e9abbb79306ce5c0cec34869000f8220175ac83d11dbe845401。

实际完整读取 hour.csv：17,379 条、17 列；day.csv：731 条、16 列；小时数据覆盖 2011-01-01 至 2012-12-31。逐行验证 cnt = casual + registered 均成立。

值得记录的质量差异：发布页 Instances 显示 17,389，而本次下载的 hour.csv 实际为 17,379 条；保留差异，以文件核验结果描述本次输入，不静默修改记录数。

适合的问题：工作日与非工作日小时需求的区别、星期与小时热力图、注册与非注册租赁次数比较、不同天气组的需求差异。

限制：cnt 是租赁次数，不是独立人数、车辆库存或收入；无站点字段，不能做站点地图；天气变量包含归一化值，未按原始文档还原前不能把它当作原单位。按工作日/天气比较需要说明组内样本量和聚合口径；缺少某小时记录不等于该小时需求为零；不能从组间差异直接宣布因果。

### 3.3 暂缓的真实电商交易数据

[UCI Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail) 官方说明含 541,909 条交易明细、数量、单价及取消标记，业务价值较高。但我们当前最多 100,000 行，暂不作为已支持案例。没有下载其完整工作簿或进行全量验收；不能为了演示静默删掉大部分数据。后续若选择它，先解决完整输入和性能，或把有明确筛选条件及原始来源的真实子集单独标明。

## 4. 与当前项目的差距及建议顺序

| 优先级 | 建议 | 当前基础 | 验收方式 |
| --- | --- | --- | --- |
| P0-1 | 保存并复用分析口径，支持有限的派生指标与分子/分母 | 已有场景定位、字段角色、单位、六类聚合 | 更换目标后仍沿用已确认单位；转化率同时展示购买会话数、全部会话数和公式；分母为零时返回不可计算 |
| P0-2 | 同一问题输出关联的指标、比较、图表和结论 | 已能执行多个任务，但报告为单任务 | 所有展示数字可追到实际计算；图表标题、过滤器与结论口径一致；数据不足时只展示能成立的部分 |
| P0-3 | 图表选区传递给追问与比较 | 已有点击图表查看来源 | 从一个图表分组发起追问，下一次真实查询含相同范围；支持撤销范围，历史结果不被覆盖 |
| P0-4 | 分析版本与追问分支 | 已有计划和任务状态，未完成完整分支 | 能返回之前一次结果，查看当时口径和数据指纹；新分支不修改旧分支 |
| P0-5 | 整份分析报告导出 | 当前 HTML 以单任务为主 | 导出当前选定分析的所有保留图表、SQL、来源和限制，无需联网读取图表资源 |

以上为本轮建议，并非五项已经完成。多图不等于分析更深；数据与问题只支持一个比较时，不凑图表数量。模型接口设置继续作为辅助配置，核心页面优先服务数据定位、计算、比较与解释。
