# 数鉴 Agent 本地比赛版增量说明

日期：2026-10-15。本文记录已实现的增量，历史 PRD 中的未来规划不视为已经交付。

## 本次范围

- 助手改为非模态浮动窗口，右下角点击打开，支持收起、桌面拖动、展开、还原、Escape 关闭与键盘焦点恢复。收起不卸载助手，请求与计划仍保留；完整刷新仍会清空分析会话。
- 本机网页可保存、修改、删除连接，刷新或重启服务仍可使用。密钥留空保留，填写替换；密钥不从状态接口读回。浏览器记住助手所选连接。
- 设置独立默认分析模型，作为产品内置 AI 初步定位入口；助手选择另一模型不改变默认定位模型。没有真实配置时明确引导设置，不产生预设结果。
- 上传后的初步定位包含摘要、候选场景与粒度、字段候选、质量风险、澄清问题、建议方向和边界。默认只发送字段与质量元数据，可补充业务背景，单独授权每列最多三个原始值示例。自动定位授权仅覆盖元数据。
- 建议方向打开助手，带入问题和用户实际填写的业务背景，不把模型猜测作为已确认背景。计算仍需人工确认口径。

## 数据与凭据

连接保存到 .local/model-connections.json，当前采用单机明文配置文件，不宣称操作系统密钥库加密。目录已排除 Git，Vite 禁止访问 .local 和 artifacts；生产静态托管只暴露 dist。GET 状态不返回密钥，远程访问不能管理配置，本机管理检查来源、Host 与实际套接字地址。每次变更顺序写入临时文件后替换，存储损坏不静默覆盖。

内置 AI 指集成默认分析服务与专业约束，不是捆绑免费模型，也不是应用内置模型权重。部署者首次配置真实接口后，使用者无需每次填写；公开部署前仍需访问控制和额度管理。

## 当前验收边界

当前仅 CSV，工具仍是受约束分组求和/均值、筛选和时间分桶；XLSX/PDF、SQL、完整自主 Agent、RAG 等不在本轮交付之内。不能以“只有服务器没上线”宣称全套比赛需求已完成。MCP 继续搁置。

模型契约测试使用显式本地 HTTP 替身；真实数据回归使用此前已获取的 OWID 中国年度子集，不以缓存回归冒充实时网络采集或真实商业模型评测。
