# 数据出处与引用

## 页面入口

导入数据后，工作台会显示数据出处摘要。点击“查看 / 备注出处”或导航“数据与来源”，可查看引用、下载地址、许可、获取日期、范围、原文件与当前快照指纹，并填写自己的备注。

## 状态含义

- **公开文件匹配**：当前仅对已核验的 UCI 电商原始 CSV 做精确 SHA-256 匹配。不依赖文件名，不能推广为任意文件的自动来源识别。哈希匹配只证明文件一致性，不证明每条记录正确。
- **公开仓库载入**：从 OWID 仓库固定提交 `e7897aed55b514b8d16e0a3d8f1518789ac3de31` 读取（同一地址始终返回同一文件），来源页显示固定提交与短哈希；各字段上游提供方、许可和业务定义仍需核对。固定提交与 `tests/fixtures/owid-provenance.json` 的核验版本一致。
- **上传者备注**：上传者填写的信息，未独立核验。添加链接不等于系统验证了内容。
- **用户提供**：未填写出处，不推断发布机构、许可、代表性或采集时间。

## 报告与数据处理

四类 HTML 报告均包含完整出处与引用。CSV 原文件指纹按上传字节计算；Excel / PDF 保留导入器的原文件指纹。清理产生新快照，仍保留原文件指纹、处理前快照和步骤。原始数据节选不等同完整源文件；记录索引仍保留。

来源备注随当前工作区保存到此浏览器；显示“已保存到本机”后刷新可恢复，页面切换和数据清理后也保留。重新导入会替换当前工作区。导出 HTML 可保留备注。来源备注不自动发给 AI；需要模型参考的业务说明请在分析背景中提供。

## 安全与不确定性

备注作为文本转义；链接仅允许不含账号密码的 HTTP / HTTPS。未提供许可时，报告明确提示不能默认允许公开再分发。获取日期与载入时间均不等于数据采集时间。对未知的年份、渠道编码和人群定义，不补造含义。

## 外部真实数据样例

演示数据的总索引、哈希与下载方式见 [demo-data/README.md](../demo-data/README.md)。这些文件均不自动载入产品，需要用户手动上传。

- `tests/fixtures/owid-China-2015-2022.csv`：OWID energy-data 固定提交的中国 2015–2022 五列，8 行；来源与逐单元格核对见 `owid-provenance.json`。
- `tests/fixtures/uci-online-shoppers.csv`：UCI Online Shoppers 原始 CSV，12,330 行 × 18 列，CC BY 4.0；哈希与口径提醒见该目录的 `uci-online-shoppers-source.md`。`Revenue` 是购买结果，不是营收。
- `demo-data/airbnb-amsterdam-2026-09-16/`：Inside Airbnb 阿姆斯特丹 2026-09-16 快照，CC BY 4.0；来源、下载地址、快照日期、SHA-256、再分发限制和口径提醒见该目录的 `README.md`。仓库只提交报告、图表、指标与截图，原始 CSV 不提交；重新下载后哈希需一致。

## 验证

运行 npm run test:core（含5项来源检查）；python tests/provenance-browser.py（真实文件上传、匹配、填写、导出、手机布局及处理后来源保留）；python tests/real-ecommerce-browser.py（真实模型完整报告引用）。浏览器脚本默认使用本地5174端口，可设置TEST_BASE_URL。
