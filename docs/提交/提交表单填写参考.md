# 提交表单填写参考（第 5–7 项）

> 用途：在提交页直接对照填写。
> 标注 **【待填写】** 的内容必须用你自己账号里真实生成的链接替换。我没有替你生成网盘或视频链接：这类链接需要你的账号上传后才能产生，编造的链接评审打不开，会按材料不完整处理。

## 五、完整作品文件链接

表单要求：把作品文档、源码等完整文件上传到百度网盘、夸克网盘、阿里云盘等主流网盘，填写有效、可访问的链接（建议长期有效、含提取码）。

### 已准备好的文件

- 完整作品包：`backups/数鉴Agent-完整作品文件-2026-10-31.zip`
- 大小：约 6.7 MB，270 个条目
- 内容：`src/`、`server/`、`functions/`、`tests/`、`scripts/`、`docs/`、`design/`、构建配置与说明文档；含作品介绍文档 DOCX / PDF 与截图
- 不包含：`node_modules`、`dist`、`.git`、`backups`、`.local`、任何 `.env` 真实值、密钥或令牌（只保留 `.env.example`）

### 上传步骤（任选一个网盘）

1. 打开网盘客户端或网页版，新建文件夹 `数鉴Agent-完整作品文件`。
2. 上传上面那个 ZIP（上传后不要改名，便于评审核对）。
3. 对该文件或文件夹创建分享：
   - 有效期选「长期有效」或「永久」；
   - 建议设置 4 位提取码；
   - 权限选「可下载」。
4. 复制分享链接，在**无痕窗口**打开，确认无需登录即可看到文件并能下载。
5. 填写到表单，格式示例：

```
网盘：<百度网盘 / 夸克网盘 / 阿里云盘>
链接：【待填写：分享链接】
提取码：【待填写：4 位提取码】（未设置则删除此项）
```

### 注意

- 不要填 GitHub 仓库地址代替网盘链接；表单明确要求网盘。
- 不要填本机路径（如 `D:\...` 或 `backups\...`），评审无法访问。
- 上传完成后先自己下载一次，确认压缩包能正常解压、`docs/提交/数鉴Agent-作品介绍.docx` 能打开。

## 七、演示视频地址

表单要求：视频上传到 B 站、抖音等可公开访问的平台，只填视频链接（`https://...`），不要交百度网盘链接。

赛事规则另要求：**5–8 分钟、MP4、不低于 1080p、普通话讲解**。建议按 6 分钟左右录制，脚本见 `docs/提交/演示视频脚本.md`。

### 录制

1. 用 OBS 或系统录屏，分辨率 1920×1080，30 fps，麦克风单独测试。
2. 浏览器全屏，缩放 100%，关闭书签栏、通知和与作品无关的标签页。
3. 提前打开公网地址，确认右上角模型状态可用；先完整走一遍流程，避免录制时等待。
4. 录制时不要展示任何 API Key、云平台控制台、账单或个人信息。
5. 如果演示中模型服务临时失败，如实展示错误提示并重试；不要剪辑成假成功。

### 上传到 B 站（推荐）

1. 登录 B 站，进入「投稿」→「视频投稿」，上传 MP4。
2. 标题建议：`数鉴 Agent：让数据分析的每个数字都有依据｜AI 数据分析与可视化`
3. 简介写清：作品名称、赛道、在线体验地址、源码仓库；可附 3–5 个功能要点。
4. 分区选「科技」→「计算机技术」或「软件应用」，标签加 `AI`、`数据分析`、`可视化`、`Web开发`。
5. 发布后设为「公开」，等审核通过，复制视频页 URL（形如 `https://www.bilibili.com/video/BVxxxxxxxxxx`）。
6. 用无痕窗口打开链接，确认不登录也能播放。

### 填写

```
视频地址：【待填写：https://www.bilibili.com/video/BV...】
```

### 注意

- 抖音链接也可以，但 B 站更适合 6 分钟横屏讲解，评审打开成本低。
- 不要填草稿链接、投稿管理页链接或带登录态的短链。
- 视频公开后不要删除或设为私密，评审期需要持续可访问。
