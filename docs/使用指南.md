# 使用指南

## 1. 导入与核对

选择 CSV、XLSX、XLS 或 PDF 文件。单文件上限 30 MB；Excel 需核对工作表、表头与数据范围，PDF 需对照原页确认提取结果。先检查字段类型、缺失值、单位及每行代表的对象，再开始分析。

在“数据与来源”中补充出处、引用与业务口径。用户自行填写的来源信息会标记为未独立核验，不会因为填了链接就自动认证。

## 2. 使用 AI

点击“连接 AI”选择模型，再打开右下角分析助手。提出问题；背景、字段定义、单位等可选补充。系统根据已授权的数据摘要生成初步定位或计划，确认后执行真实计算，最后结合结果解读。

原文件在浏览器处理。字段摘要、少量原始样本、类别字典和 PDF 图像按页面授权发送给所选模型。业务名称、编码和单位不明确时应补充说明，不能把模型猜测直接作为事实。

本机运行可在弹窗添加、测试、切换和编辑 OpenAI 兼容 Chat Completions 连接。连接保存在本机服务的 `.local` 目录中，该目录不得公开。已保存的密钥不会通过状态接口回传浏览器。

公网运行由部署者配置默认模型；访客不能修改服务端凭据。若部署者允许访客自填接口，目标 HTTPS 域名必须在服务端白名单内，访客密钥仅保留于当前页面内存。

## 3. 查看图表与追问

在分析结果中切换任务，查看图表和分组表格。选择分组后可围绕该范围继续提问并重新计算；原结果保留在分析路径中，便于返回对照。没有模型连接时，可以使用手动探索和对比计算。

## 4. 回查与导出

打开证据面板，核对 SQL、统计口径、结果与原始记录。报告导出为单文件 HTML，包含当前分析及数据出处。报告中的原始记录节选不等于完整源文件。

工作区保存在当前设备、浏览器和站点地址。刷新恢复不会自动重复调用模型；换浏览器、换域名或换设备不会自动同步。公开分享报告前，先确认其中记录可对外披露。
