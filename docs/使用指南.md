# 使用指南

## 1. 导入与核对

选择 CSV、XLSX、XLS 或 PDF 文件。单文件上限 30 MB；Excel 需核对工作表、表头与数据范围，PDF 需对照原页确认提取结果。标准 CSV 直接读入；若首行是导出标题、各行列数不一致、表头为空或重复，会自动打开导入预览，由你选择表头所在行与数据截止行，确认后才进入分析。先检查字段类型、缺失值、单位及每行代表的对象，再开始分析。数据处理页还提供数值区间分布，以及缺失、非数值、首尾空白、IQR 异常和整行重复候选的分页核查；这些只是候选，不会自动删除或改写原值。

在“数据与来源”中补充出处、引用与业务口径。用户自行填写的来源信息会标记为未独立核验，不会因为填了链接就自动认证。

## 2. 使用 AI

点击“连接 AI”选择模型，再打开右下角分析助手。提出问题；背景、字段定义、单位等可选补充。系统根据已授权的数据摘要生成初步定位或计划，确认后执行真实计算，最后结合结果解读。执行计划时会显示逐任务进度，可随时停止；已完成的真实结果保留，确认后可仅继续未完成的任务。

原文件在浏览器处理。字段摘要、少量原始样本、类别字典和 PDF 图像按页面授权发送给所选模型。你在“类型不对？纠正”里确认过的字段角色会随摘要作为已确认类型发送：模型会按该类型使用字段，但它仍不知道业务含义、行粒度或总体范围，这些需要你在背景里补充。业务名称、编码和单位不明确时应补充说明，不能把模型猜测直接作为事实。

需要核对指标口径时，可展开“参考资料与本地检索（可选）”，上传 PDF、TXT 或 Markdown。文件只在浏览器内切分，检索也在本地完成；提问时只发送命中的摘录（最多四段，合计不超过 6000 字），不发送整份资料。内置方法库会按问题召回缺失值、分母、相关与因果等提示，无需上传文件。读取 PDF 时保留页码，扫描件若没有文字层会明确拒绝。资料摘录会随“分析计划”和“结果解读”发送；解读引用资料时显示编号，模型引用未提供的编号会被服务端拒绝。参考资料不是计算结果或证据，不进入数据快照、图表与报告，刷新或更换数据后清空。

本机运行可在弹窗添加、测试、切换和编辑 OpenAI 兼容 Chat Completions 连接。连接保存在本机服务的 `.local` 目录中，该目录不得公开。已保存的密钥不会通过状态接口回传浏览器。

公网运行由部署者配置默认模型；访客不能修改服务端凭据。若部署者允许访客自填接口，目标 HTTPS 域名必须在服务端白名单内，访客密钥仅保留于当前页面内存。

## 3. 查看图表与追问

在分析结果中切换任务，查看图表和分组表格。选择分组后可围绕该范围继续提问并重新计算；原结果保留在分析路径中，便于返回对照。没有模型连接时，可以使用手动探索和对比计算。

每次计算保存在“分析分支”中，可随时切回原来的口径。分支可重命名：只改变显示名称，分组、指标、筛选、SQL、数值和来源证据都不变。删除分支前会二次确认；删除一个分支时，它的追问结果会一并删除，包含这些结果的 AI 分析（含解读与引用）也会整项移除，避免留下无法回查的引用。数据、字段纠正和已导出的文件不受影响，删除不可撤销，重要结果请先导出报告。

结果卡下方的“指标单位”用于记录数值代表什么。它只是标注：保存后图表坐标轴、无障碍描述、确定性结论、结果表、HTML 报告、结果 CSV 与可复现包会使用同一单位，但 SQL、分组值和比例分母都不会改变。分析计划已经带入单位时，状态显示为“口径单位”，表示该单位来自已确认的分析口径、尚未记为你的声明；点击“确认并记录”后才会显示“已声明”。把输入框清空并保存可撤回声明。比例结果固定使用 %，不能另声明单位。

探索分析的折线图在按年或按月分桶后，会附带一条描述性线性趋势：对图中的时间点做最小二乘拟合，显示平均每期变化和 R²。它只描述图中已经计算出的聚合值，不是预测、显著性检验或因果结论；分组缺失、时间点不等距或指标口径变化都会影响斜率。分类维度（不分桶）不会显示趋势。

散点图会附带 Pearson 线性相关系数：r 介于 -1 与 1 之间，并显示参与计算的有效配对数。系数按**当前筛选下的全部有效配对**计算，不受“最多展示项数”限制；图只画前若干条记录时，卡片会明确提示两者覆盖范围不同。相关系数只描述线性同步程度，不是因果结论、预测能力或显著性检验；极端值、非线性关系、分组缺失和共同时间趋势都会影响数值。有效配对少于三条或任一字段为常数时不显示系数。

## 4. 回查与导出

打开证据面板，核对 SQL、统计口径、结果与原始记录。报告导出为单文件 HTML，包含当前分析及数据出处。报告中的原始记录节选不等于完整源文件。报告与结果 CSV 会注明指标单位及其来源（由你声明 / 来自当前分析口径），并明确单位不参与计算；可复现包的 `expected.json` 也记录该单位，复算时仍按同一 SQL 与参数执行。

同一面板还可导出“可复现 SQL 包”（探索分析页也有同一按钮）。ZIP 内包含当前清洗后数据快照 `data.csv`、SQLite `schema.sql`、参数已内联的 `analysis.sql`、记录结果与来源的 `expected.json`，以及仅依赖 Python 标准库的 `run_analysis.py`。在本机解压后执行 `python run_analysis.py`，脚本会重建数据库、重跑同一条 SQL 并逐行核对；输出 `PASS` 表示复算一致。包只保证 SQLite + Python 路径，换成 DuckDB/PostgreSQL 需自行实现同名 UDF。结果只对包内快照成立，换数据后需重新导出。

## 5. 自己写 SQL

顶部“SQL 查询”进入只读控制台。左侧列出 `data`（cN 列名）与原表头视图 `readable` 的映射，以及 `strict_number` / `compare_labels` / `time_bucket` 三个函数。输入一条 SELECT 或 WITH 查询，点“运行查询”（或 Ctrl / Cmd + Enter）即可在浏览器 Worker 的当前快照上执行；最多返回 500 行，超出会提示并只导出显示部分。

控制台拒绝写操作、DDL、PRAGMA、事务、参数占位符、`sqlite_*` 内部表和一次多条语句。字符串或注释里的关键字、分号不算违规。

查询成功后可以点“结果图表”，把返回行画成柱形图或折线图。横轴可以选任一列或结果行号，纵轴只列出能严格解析为数值的列；文本、空值、`$1,234` 这类字符串不会被当作 0。图表不重新聚合、不插补缺失值；要回查来源，请在 SQL 里选择 `_record`。纯文本结果不会出现数值图，只会提示没有可用的纵轴。

需要关联第二张表时，在左侧“关联表（可选）”上传 CSV。它在本会话内以固定名字 `extra` 可用（原表头视图为 `extra_readable`，`_row` 是数据行号），上传后可点“填入 JOIN 示例”。示例会在数据中查找真实存在共同值的列，但仍需你确认两侧是不是同一口径；找不到共同值时它会明确提示，需要手动改连接键。关联表不写入快照、不进入图表或报告，切换数据、刷新页面或“移除关联表”后消失。

## 6. 工作区与分享

工作区保存在当前设备、浏览器和站点地址。刷新恢复不会自动重复调用模型；换浏览器、换域名或换设备不会自动同步。公开分享报告前，先确认其中记录可对外披露。
