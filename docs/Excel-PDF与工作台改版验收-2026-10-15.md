# Excel / PDF 与工作台改版验收

> 本文为导入与工作台改版的阶段记录。后续真实 SQL、数据处理、五类展示与期间对比的实现和验收，见 [数据核心升级记录](数据处理分析与可视化核心升级-2026-10-15.md)。

日期：2026-10-15。范围：修正 CSV 单一导入、空状态和导入流程粗糙、分析按钮未打开助手等问题。本记录只说明实际实现与验证，不将原 PRD 里的目标能力视为已经交付。

## 1. 当前可操作流程

1. 打开工作台，不自动填入数据或分析结果。选择 CSV、Excel 或 PDF，也可主动读取 OWID 真实公开数据。
2. Excel 进入工作表选择与预览；选择表头和数据截止行，可以修订单元格。PDF 进入页面选择，左侧看原页，右侧核对提取候选。
3. 重复或空表头、范围越界、表头外存在数据、空记录集等情况会阻止确认。PDF 排版本身不等于可靠表格，不跳过人工确认。
4. 勾选核对后才替换当前数据集。取消或文件解析失败保留原数据与结果。
5. 授权默认 AI 初步定位，补充业务背景与单位；通过窗口助手提出目标，查看澄清问题，确认计划后计算。也可使用折叠的手动字段工具。
6. 查看图表、计算方法和来源记录，导出单文件 HTML 报告。Excel 来源记录对应工作表与行号；PDF 对应页码及提取行序号，还可重新打开来源原页。

“开始 AI 分析”实际打开助手；新建分析在没有数据时打开文件选择，有数据时打开助手。助手可展开、收起，模型配置可编辑保存。工作台采用新导入首页、四步流程提示、文件格式入口与独立核对窗口。

## 2. 多模态的实际范围

PDF 窗口中的“视觉模型识别当前页”是图像转录入口：用户选择支持图像输入的兼容模型，单独授权当前页 JPEG，后端向该真实地址发起 Chat Completions 请求。模型输出必须满足列名、行宽、字符串类型及规模约束；输出回到预览，仍需核对后才能导入。

当前无免费视觉模型或模型权重。文本连接测试通过不意味着图像协议一定可用。模型服务拒绝、响应不合规或超时会显示错误，已有候选保留。更换模型会撤销原授权并取消在途识别。

扫描件没有文字层时显示原页和识别入口，绝不自动生成样例或零值。没有声称“任意 PDF 识别准确”。当前一次处理一页中的一张表，不自动跨页合表、不自动执行图片或文档中的指令。

## 3. 数值与来源保护

- Excel 公式采用文件现有缓存，不重算；无缓存保持空，显示警告。Excel 错误保留为错误文本，不能将错误内部代码当作数值。
- 零填充编号保留前导零；日期保留时刻；百分比保留底层比例并提示确认单位。合并单元格不自动填充。
- 不默默移除逗号、货币符号、括号等改变文本语义；此类清理当前需要用户在预览中核对修订或先清理源文件。
- 原文件 SHA-256 与确认后的数据快照指纹分开保存；两个工作表、不同页面或不同修订不会共用同一分析指纹。
- HTML 报告包含文件哈希、解析方式、警告、分组来源记录，PDF 来源页以 JPEG 内嵌，图表以 SVG 内嵌。
- 用户修订记录在读取方式中，尚无逐单元格修改审计。PDF 提取行序号不是 PDF 物理行号。

计算基准是此前实际取得的 OWID energy-data 中国 2015—2022 子集，逐项与 Python 独立读取的原值核对。XLSX、XLS、文字 PDF 和图像 PDF 都由同一真实 CSV 保真转换，文件仅放在忽略提交的测试产物目录。它们验证格式和计算链路，不是对任意财报或互联网平台数据的通用准确率评测。人为错误字符串仅用于解析契约测试，不进入产品数据。

本轮模型请求验证使用明确标记的本地 HTTP 替身，没有使用真实厂商密钥，不证明实际模型的规划或 OCR 质量。截图已生成，当前图片查看工具不支持图像输入，未声称完成人工视觉截图审查。

测试使用 5180 / 5181 的隔离配置，不修改用户在 5174 服务中保存的模型凭据。

## 6. 尚未达到比赛最终交付的内容

当前计算仍为受约束的 JavaScript 分组统计，未实现 SQL 引擎、跨表关联、完整自主 Agent 重规划、多假设自动检验、RAG 或散点/热力图。仅支持折线、柱状和结果表。MCP 继续按已确认范围搁置。

文件上限 30 MB、100,000 条记录、200 列；Excel 最多 50 张工作表、200 万个矩形单元格；PDF 最多 100 页。视觉转录每页最多 40 列、300 行，超范围应拒绝，不以截断后的结果冒充完整表格。数据和分析分支仍保存在内存，刷新会清空。

公网部署、真实服务商兼容矩阵、典型中文财报及扫描件质量评测、比赛视频与技术文档，均尚未完成验收。因此当前应称为完成本轮导入与分析链路修正的本地功能原型，不能称为最终比赛成品。
