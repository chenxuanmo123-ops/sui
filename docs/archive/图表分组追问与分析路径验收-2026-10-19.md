# 图表分组追问与分析路径验收

日期：2026-10-19。状态：功能已实现，使用已保存的真实模型完成当前单案例验收；不代表通用分析准确率。

## 用户可以完成的操作

1. 上传真实文件，使用 AI 提出并确认分析计划，得到实际 SQL 结果。
2. 点击结果图形或表格分组，查看所选分组、指标值与完整匹配记录数。
3. 点击“围绕此分组追问”，修改问题，继续生成计划并计算。
4. 计算引擎锁定来源分组的匹配记录；即使模型没有重复原筛选条件，也无法扩大到全表。进一步筛选可以缩小范围。
5. 通过“分析路径”或“返回来源分析对照”切换原结果和追问结果。
6. 导出包含 SVG、SQL、参数、分组范围、基准值、来源索引与数据出处的单文件 HTML。

单项结果采用桌面端图表与表格并排布局；移动端纵向显示。比例追问仅在指标、单位、分子和分母口径一致时显示与来源分组的百分点差值。AI 解读区分数据观察和待验证解释，证据按钮显示分组名称与数值。

## 数据与真实模型验收

数据：UCI Online Shoppers Purchasing Intention Dataset，Sakar 与 Kastro，2018。

- DOI：10.24432/C5F88Q；许可：CC BY 4.0。
- 使用原始 CSV：12,330 行、18 列。
- 文件：`tests/fixtures/uci-online-shoppers.csv`。
- SHA-256：`b3055ee355f59134d851d32641183cb4a8b45def7124d2f50442a042f358e0d9`。
- 每行是一次访问，不是一个独立用户；Revenue 是购买布尔结果，不是营收金额。历史样本不能外推当前市场。

通过本地网页调用已保存的真实模型，初始规划、初始解读、分组追问规划、追问解读均返回 HTTP 200。未模拟这些响应，未读取或修改保存凭据。与独立 Python 逐组核算一致：

| 计算范围 | 分子 | 分母 | 购买转化率 | 相对新访客基准 |
| --- | ---: | ---: | ---: | ---: |
| 全表 | 1908 | 12330 | 15.4745% | 不适用 |
| New_Visitor | 422 | 1694 | 24.9115% | 基准 |
| 新访客中 Weekend=FALSE | 317 | 1215 | 26.0905% | +1.18 个百分点 |
| 新访客中 Weekend=TRUE | 105 | 479 | 21.9207% | -2.99 个百分点 |

仅做描述性比较，未证明周末影响购买的因果关系。

## 校验与隐私

范围包含当前快照指纹、载入时间、来源分析编号、分组和完整匹配记录索引；旧快照、越界、重复或非整数索引均拒绝执行。范围在工作线程内再次验证，并通过 `_record IN (...)` 限定实际 SQL。即使原指标为空，匹配分组的记录也保留在追问范围内，避免质量检查漏行。

来源分组名称、记录数和基准值会随用户提交追问发送给模型；完整来源索引在本地使用，不发送模型。原始值样本与类别字典仍分别授权，默认关闭。解除范围会使旧计划失效。继承同一比例指标时校验分子分母口径；失败任务修正保留范围。

## 尚未完成与适用边界
