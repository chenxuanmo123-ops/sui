## 3. 与现有分析能力的连接

- server/ai.mjs 接收网页临时 provider 配置，使用其实际 baseURL、apiKey、model 和 JSON 开关调用兼容上游。
- POST /api/ai/models 真正调用上游 /models；不保证每家提供列表，允许手动输入。
- POST /api/ai/test 真正发起小额文本模型请求；不会返回上游原文或凭据。测试成功不等于分析协议已兼容。
- /plan 和 /review 继续用专业数据分析规划/复核提示词与严格结构校验。模型负责计划与解释，实际数值仍来自本地计算。
- 公网自填接口需要部署者精确配置 LLM_ALLOWED_HOSTS，使用 HTTPS，不跟随重定向；本机访问支持本机 HTTP 兼容模型。该域名限制并不等同完整公网安全审计。

## 6. 本轮导入工作台落实（2026-10-15）

本轮进一步对照 Data Formulator 的 `src/views/DataLoadingChat.tsx`（commit `5477f0e236426dc8f74a498ec400414fba7fbc0f`）：其核心不是“点上传就直接算”，而是先生成数据候选预览，再由用户确认后载入。数鉴把这个原则落实为 `src/ImportDialog.tsx`：

- Excel 工作簿先列出工作表，再选表头行和数据末行；表格预览允许修订单元格，重复字段、越界范围、空表头和列溢出会阻止导入。
- PDF 先按页读取文字位置并同时保存当前原页图像；PDF 不是天然表格，列对齐只能作为候选，用户必须核对，扫描 PDF 没有文字层时不会填入虚构数据。
- 图像模型入口只提交当前页 JPEG，必须显式授权并选择已配置模型；服务端要求严格 JSON 表格契约，结果再次进入预览，不直接计算。
- `src/importers.ts` 保存 SHA-256、工作表/页码、表头原行、来源行位置、读取方式和警告；`src/App.tsx` 将这些信息写入来源视图和 HTML 证据报告。

这部分借鉴的是“导入候选与确认载入”的产品交互和边界控制，不是复制 Data Formulator 代码，也不表示对任意 PDF、扫描件或模型 OCR 准确率作保证。

本轮新增的真实回归基准是 Our World in Data 的公开能源数据子集，测试文件由该真实 CSV 保真转换为 XLSX、XLS、文字 PDF 与扫描 PDF，仅用于验证格式链路，不作为应用内置业务数据。
