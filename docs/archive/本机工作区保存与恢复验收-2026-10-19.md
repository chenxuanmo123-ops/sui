# 本机工作区保存与恢复验收

日期：2026-10-19。当前阶段：本地比赛版功能完善，未进行公网部署。

## 实际完成

数据载入后自动将当前工作区保存在此浏览器的 IndexedDB，400 ms 合并连续修改，按事务完成事件确认保存成功。刷新时先恢复并核对数据关联，再开放工作台操作。

保存内容：当前数据与原文件解析定位、来源备注、数据处理撤销快照、已完成的计算历史、完整分析结果及已有 AI 解读、父分析与分组范围、当前分析路径、字段口径、页面位置，以及探索/对比页面配置和结果。不保存未提交的助手草稿、进行中的模型请求或 SQL 任务；不把 API Key 或模型连接配置写入这个工作区。

页面明确显示“等待保存”“正在保存”“已保存到本机”或失败原因。空间不足时保留当前内存结果，提供“重试保存”和报告导出。恢复旧工作区时，即使此前允许上传后自动定位，也不会重新触发初步定位；手动重新定位仍可用，新导入继续遵循此前授权。

提供“清除本机工作区”确认窗口，可以取消；确认后删除保存内容并重置工作台，原始文件、已导出报告及模型连接配置保留。写入和清除按序执行，取消尚未开始的保存，避免旧任务写回。新导入会替换当前工作区。

## 恢复校验与错误处理

使用版本化记录。恢复时检查记录版本、必要状态、数据表结构、快照指纹、载入时间、计算编号、结果快照、分组来源索引、分析路径以及探索/对比快照关联。旧版本或损坏关联停止恢复并保留记录，不用空状态覆盖；用户可通过清除入口重新开始。这些检查不代表重新证明数据来源真实性或模型语义正确性。

数据库不可用、被其他页面阻止升级、操作超时和存储额度不足都有失败提示。后台切换和离开页面会尽力提交待保存内容，浏览器突然关闭时不能保证尚未完成的写入，因此以页面显示“已保存到本机”为准。

## 真实数据与测试方式

使用 UCI 原始 Online Shoppers Purchasing Intention CSV，12,330 条访问，18 列；来源 DOI 10.24432/C5F88Q，CC BY 4.0。每行是一次访问，Revenue 是购买布尔结果，不是金额。SQL 在实际浏览器 SQLite Worker 中执行。

本轮工作区浏览器验收使用明确标注的 AI 规划/解读测试替身，以隔离存储与界面机制，不作为新一轮真实模型准确率成绩。此前真实模型分组追问验收保留于 artifacts/follow-up-real-acceptance/，没有混用两类成绩。

关键核算：全表 1908/12330=15.47%；新访客 422/1694=24.91%。刷新恢复后再对 Weekend=FALSE 子组发起追问，实际 SQL 仍限定到 1,215 条记录，得到 317/1215=26.09%。保存/恢复时不重新运行模型或改写这些已完成结果。

机制测试包括显式模拟浏览器额度不足、将存储版本修改为未知版本、确认后对原文件做去重再撤销。它们只验证错误与撤销处理；没有伪造业务数据，也没有把完全相同的访问断定为错误记录。

## 使用与限制

这是同一个浏览器、同一个站点地址下的一份当前工作区。localhost 与 127.0.0.1、不同端口或部署域名属于不同来源，记录不会自动迁移。清除站点数据或使用会自动清理的隐私窗口可能丢失记录，请导出需长期留存的报告。尚无跨设备同步、多个工作区列表、持久化文件版本树或多个标签页的编辑冲突保护；建议同一地址保留一个编辑页面。

初步定位的候选建议和助手未提交草稿没有纳入保存；已完成分析的解读保存在结果中。原始文件本身不会保存为文件附件，但解析后的表格、定位、原文件指纹及已有 PDF 页图会随工作区保存。未验证 100,000 行乘 200 列的保存性能和各浏览器极限容量。
