# 数鉴 Agent 演示脚本（提交版）

用途：比赛答辩现场按顺序演示，保证每一步都落到真实数据与可核查证据上。视频录制以 [提交/演示视频脚本](提交/演示视频脚本.md) 为准；本页是同一主线的现场速查版。

## 演示前检查

1. 打开 <https://sui-ae9.pages.dev/>，确认右上角模型状态为“已配置”（`/api/ai/status` 返回 `configured: true`）。
2. 点击“手边没有文件？从网页直接下载公开数据”：OWID 能源数据，固定提交 `e7897aed`，9,229,369 B，SHA-256 校验后载入，23,377 行 × 130 字段，1900–2025。
3. 若图表分包被网络截断，页面会提示“图表引擎加载失败”，结果表、SQL 与来源记录仍可用；刷新即可恢复。
4. 总纲：**数字全部来自浏览器内 SQLite 的真实计算，AI 只负责理解问题、规划口径与解释已验证结果。**

## 场景 1：单一国家的时间趋势（主推）

提问：`中国 2000 到 2023 年的石油产量怎么变化？`

真实模型实际计划（2026-10-31 本地真实模型复验）：

| 任务 | 分组 | 指标 | 汇总 | 筛选与范围 |
| --- | --- | --- | --- | --- |
| T1 主任务：石油产量逐年变化 | `year` | `oil_production` | 求和 | `country = China`，2000–2023 |
| T2 人均石油产量 | `year` | `oil_prod_per_capita` | 求和 | 同上 |
| T3 记录数与缺失年份核查 | `year` | `oil_production` | 记录数 | 同上 |
| T4 同比变化率 | `year` | `oil_prod_change_pct` | 求和 | 同上 |

确认前核对：国家、年份范围、指标、聚合方式。计划把单位标为“未确认”——字段说明是 TWh 一次能源，但模型没有替用户断言，讲解时也不能说成模型结论。

确认后真实计算（T1）：24 个年度值，2000 年 1,891.27、2023 年 2,430.97（TWh，字段标注）；最高 2015 年 2,495.33，最低 2000 年 1,891.27。按首尾值算：+539.70，约 +28.5%，平均每年 +23.47。

要点讲述：
- 这是描述性汇总，不是预测，也不说明原因。
- 逐点回查国家—年份原始行；SQL 与参数在页面中可见。
- T3 用于核对“每年是否恰好一条”，避免把缺失年份当零产量。

## 场景 2：多轮追问（消费量）

在结果页打开 AI 助手，于“沿着发现，继续追问”输入：`那同期石油消费量呢？`

预期计划：指标改为 `oil_consumption`，仍按年份、`country = China`、2000–2023；同样先核对再确认。

真实数据（固定 CSV 独立复算，待现场计划一致时使用）：2023 年 9,091.23 TWh，与产量 2,430.97 相差 6,660.26 TWh；2000 年 2,626.90 TWh，到 2023 年约 +246.1%。

要点讲述：两个总量都在上升，但不能凭产量与消费推断进口依赖，也不能写成因果。

## 场景 3：两个数值字段的关系（散点 + Pearson r）

探索分析 → 散点图：X「石油消费量（TWh）」、Y「石油产量（TWh）」；筛选字段「国家/地区」，精确匹配值输入原始值 `China`；上限 100。

结果：60 对有效值（1965–2024），r = 0.8191；60 点在图中全部显示（未截断），卡片写明“与图中点数一致”。

要点讲述：r 只描述线性同步程度，不是因果、预测或显著性检验；共同时间趋势与极端值都会影响 r。

## 必须说到的边界

- OWID 是国家—年份面板，不是每国每年齐全：2023 年石油产量只有 79 个国家/地区有值。
- `World`、`Asia` 等是聚合行（`iso_code` 为空），不是国家。
- 单位是 TWh 一次能源，不是桶，也不是金额；2024 年以后数据不完整。
- 样本不等于总体；描述统计不写因果结论；缺失年份不当零产量。
- 模型未确认的字段含义进入澄清问题，不当成已验证事实。
- 模型不可用或余额不足时页面明确报错，不生成假结果。

## 现场故障预案

| 现象 | 处理 |
| --- | --- |
| 公网页打不开 | 切本地 `npm run dev`，或播放提前录好的屏幕 |
| 下载公开数据慢 | 讲解 SHA-256 校验机制，等待完成；不要跳过校验 |
| 模型超时/报错 | 先讲手动探索与真实 SQL，再重试；不现场调试密钥 |
| 计划条件不符 | 展示计划并指出差异，修正条件后重算；不照读旧数字 |
| 复核未返回 | 如实说明仍在生成；不影响已算出的结果与证据 |
